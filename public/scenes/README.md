# Scene background records

The five backgrounds in this directory were generated for the Avatar Companion MVP with OpenAI's built-in image generation tool on 2026-08-14.

- `office.jpg`: contemporary company workspace
- `gym.jpg`: modern boutique gym
- `beach.jpg`: quiet coastal cove
- `nature.jpg`: forest and lake clearing
- `cafe.jpg`: contemporary coffee shop

All prompts required an empty environment, a calm central full-body avatar placement zone, responsive centered portrait cropping, and no people, logos, readable text, UI, or watermarks. The original 1536 x 1024 PNG outputs were converted locally to quality-86 JPEG files for the mobile bundle. No third-party source images were used.

Dedicated `*-portrait.jpg` compositions were generated with the same built-in image tool on 2026-08-16 using each landscape scene as the edit target and visual reference. They are native 941 x 1672 scenes rather than center crops, with recognizable environment details arranged through the full vertical frame and a clear central avatar placement zone. The generated PNG files were converted locally to quality-88 JPEG files for the mobile bundle.
